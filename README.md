## 📱 About the Project

**Aman Launcher** is a custom Android Home Launcher developed to explore modern Android launcher architecture, gesture-driven navigation, app management, Android system APIs, and media downloading functionality.

The project was developed using a combination of **software development experience, debugging, architecture decisions, testing, and AI-assisted development with Cursor**.

AI was used as a productivity tool to accelerate implementation, generate boilerplate code, explore solutions, refactor code, and assist with debugging.

All generated solutions were reviewed, tested, debugged, and integrated into the project through hands-on development.

---

## ✨ Features

### 🏠 Custom Android Launcher

* Works as the device's default Home application
* Custom Home Screen workspace
* Displays installed applications
* Smooth App Drawer navigation
* Swipe-up and swipe-down gestures
* Native-style launcher interactions

### 📱 App Management

* Launch installed applications
* App-specific Launcher Shortcuts
* Shortcut icons and labels
* App Info
* System uninstall flow
* Remove apps from Home Screen
* Long-press contextual menus

### 🖐️ Drag & Drop

* Long-press apps from the App Drawer
* Drag applications to the Home Screen
* Home Screen grid placement
* Persistent Home Screen shortcuts
* Duplicate and occupied-position handling

### 🎨 Home Screen Customization

* Native-style Home Screen long-press menu
* Wallpaper picker integration
* Home Screen Settings
* Persistent launcher configuration

### 📥 Integrated Media Downloader

* Clipboard URL detection
* Manual Paste functionality
* Media API integration
* Photo and video preview
* Video playback using AndroidX Media3
* Media downloading
* Android MediaStore integration
* Downloaded media visible in the device Gallery
* Persistent Download History
